# 作業ログ（worklog）

「P6P7_対策の検討.pdf」で決めた順番で作業を進める。
1 つの作業（ステップ）ごとに **git のブランチを 1 本**作り、**この フォルダに md ファイルを 1 つ**残す。

## ルール

1. **ブランチ**
   - 名前は `stepNN-内容`（NN は 2 桁の番号）。番号順に並び、名前を見れば内容が分かるようにする。
   - 各ステップは、1 つ前のステップのブランチから作る。終わったブランチはそのまま残し、後から比べたり戻ったりできるようにする。
   - `main` は作業を始める前の状態のまま触らない。
2. **作業ログ（この md）**
   - ファイル名はブランチ名と同じ（例：`step01-generated-verify.md`）。
   - 書く内容は次のとおり。
     - 概要：何のための作業か
     - タスク：やることのチェックリスト
     - 計画：どう進めるか、なぜそうするか
     - 実施内容：実際にやったこと、実行したコマンド
     - 変更したファイル
     - 検証結果：何をどう確かめ、どうなったか（失敗も含めて書く）
     - 残った課題・次のステップへの引き継ぎ
   - 作業の途中でも更新し、最後にコミットに含める。
3. **コミット**
   - ステップのブランチの上でコミットする。リモートへの push は、指示があるまでしない。
